# Writing tests in OpenDXP

Read the README of `open-dxp/test-foundation` before you write, move or change a test. It is the
one description of the structure, the test cases, the factories and the rules.

In a checkout it is `vendor/open-dxp/test-foundation/README.md`. Without a vendor directory, read it
at https://github.com/open-dxp/test-foundation.

Run the tests and the static checks with the OpenDXP testkit, not on the host.

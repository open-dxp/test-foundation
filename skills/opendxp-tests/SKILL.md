# Writing tests in OpenDXP

Read `vendor/open-dxp/test-foundation/README.md` before you write, move or change a test. It is the
one description of the structure, the test cases, the factories and the rules.

Run the tests and the static checks with the OpenDXP testkit, not on the host.
